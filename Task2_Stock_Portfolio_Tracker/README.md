# 📈 Stock Portfolio Tracker

A simple **Python-based Stock Portfolio Tracker** that allows users to manage their stock holdings through a menu-driven command-line interface.

## 📌 Project Overview

This project is a console-based application developed in Python. It allows users to:

* Add stocks to their portfolio
* Store the number of shares
* Store the price per share
* View all stocks in the portfolio
* Calculate the total portfolio value
* Remove stocks from the portfolio
* Exit the program

## 🛠️ Technologies Used

* **Python 3**
* **Dictionaries**
* **Loops**
* **Conditional Statements**
* **User Input**
* **Basic Arithmetic Operations**

## ⚙️ Features

### 1. Add Stock

Users can enter the stock name, number of shares, and price per share.

### 2. View Portfolio

Displays all stocks currently stored in the portfolio along with their calculated values.

### 3. Calculate Total Value

Calculates the total value of all stocks in the portfolio.

### 4. Remove Stock

Allows users to remove a stock from the portfolio.

### 5. Exit

Closes the application safely.

## ▶️ How to Run

Make sure Python 3 is installed on your computer.

Open a terminal inside the project folder and run:

```bash
python stock_tracker.py
```

Follow the menu options displayed in the terminal.
