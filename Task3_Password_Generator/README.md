# 🔐 Password Generator

A simple **Python-based Password Generator** that creates random passwords based on the length specified by the user.

## 📌 Project Overview

This project is a command-line application developed in Python. It generates random passwords using a combination of:

* Uppercase letters
* Lowercase letters
* Numbers
* Special characters

The user can specify the desired password length, and the program generates a random password accordingly.

## 🛠️ Technologies Used

* **Python 3**
* **Random Module**
* **String Module**
* **Loops**
* **User Input**

## ⚙️ Features

### 1. Custom Password Length

The user can enter the desired password length.

### 2. Random Password Generation

The program randomly selects characters to create a unique password.

### 3. Multiple Character Types

Generated passwords can contain:

* Uppercase letters (`A-Z`)
* Lowercase letters (`a-z`)
* Numbers (`0-9`)
* Special characters (`!`, `@`, `#`, `$`, etc.)

## ▶️ How to Run

Make sure Python 3 is installed on your computer.

Open a terminal inside the project folder and run:

```bash
python password_generator.py
```

The program will ask for the desired password length.

### Example: Generating a Password

Enter the desired password length:

```text
===== Password Generator =====
Enter password length: 12

Generated Password: 27?IpmdmoHF`
```

The generated password will be different each time because the program uses random character selection.
